✈️ TravelForm

📌 About the Project

TravelForm is a simple travel website project developed to practice front-end and basic backend web development.

The project includes a travel/registration form where users can enter their information. The submitted information is processed using PHP and can be stored in a MySQL database.

🚀 Features

- 🌍 Travel-themed website
- 📝 Travel/registration form
- 💾 MySQL database integration
- ⚙️ PHP backend
- 🎨 Custom CSS styling
- 💻 JavaScript functionality
- 📱 Simple and user-friendly interface

🛠️ Technologies Used

Technology| Purpose
HTML5| Website structure
CSS3| Styling and layout
JavaScript| Client-side functionality
PHP| Backend and form processing
MySQL| Database management

🎯 Project Purpose

The main purpose of this project is to practice the basics of:

- HTML forms
- CSS styling
- JavaScript
- PHP
- MySQL
- Form submission
- Database integration
- Basic client-server communication

✈️ TravelForm

📌 About the Project

TravelForm is a simple travel website project developed to practice front-end and basic backend web development.

The project includes a travel/registration form where users can enter their information. The submitted information is processed using PHP and can be stored in a MySQL database.

🚀 Features

- 🌍 Travel-themed website
- 📝 Travel/registration form
- 💾 MySQL database integration
- ⚙️ PHP backend
- 🎨 Custom CSS styling
- 💻 JavaScript functionality
- 📱 Simple and user-friendly interface

⚙️ Setup & Documentation

🚀 How to Run the Project

1. Clone the Repository

git clone https://github.com/Mahrukhkhann/TravelForm.git

2. Move the Project to XAMPP

If you are using XAMPP, place the "TravelForm" folder inside:

xampp/htdocs/

For example:

xampp/htdocs/TravelForm/

3. Start XAMPP

Open XAMPP and start:

- Apache
- MySQL

4. Set Up the Database

Open phpMyAdmin and create a MySQL database for the project.

Create the required table according to the fields used in the travel/registration form.

5. Configure the Database Connection

Make sure the database connection details in the PHP file match your local MySQL setup.

Typical local settings:

Host: localhost
Username: root
Password:
Database: your_database_name

6. Open the Website

After starting Apache and MySQL, open:

http://localhost/TravelForm/

🔄 How It Works

The basic flow of the project is:

User
  ↓
Travel / Registration Form
  ↓
JavaScript
  ↓
PHP
  ↓
MySQL Database

The user enters information into the form. The form data is sent to the PHP backend, where it can be processed and stored in the MySQL database.
